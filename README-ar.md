# محلل الأسهم الأمريكية على GitHub (كل الأسهم، بدون حسابات إضافية)

## النشر (6 خطوات)
1. github.com ← **New repository** ← سمّه `stock` ← **Public** ← **Create**.
2. **uploading an existing file** ← اسحب **كل محتويات هذا المجلد** (بما فيها `.github` و`scripts` و`data`) ← **Commit changes**.
   - إن لم يظهر `.github` في ويندوز: تبويب «عرض» ← فعّل «العناصر المخفية».
3. **Settings ← Pages ← Source: GitHub Actions** (مهم: ليس Deploy from a branch).
4. **Actions ← update-and-deploy ← Run workflow** (اترك «فحص كل السوق» مفعّلاً) ← Run.
   - أول تشغيل يستغرق 15–40 دقيقة لأنه يفحص آلاف الأسهم. إن ظهر زر «I understand my workflows» اضغطه.
5. عند ظهور علامة ✅ افتح `https://USERNAME.github.io/stock/`.
6. بعد ذلك يعمل وحده: كل 15 دقيقة أثناء السوق (تحديث القائمة)، وبعد الإغلاق (فحص كل السوق).

## كيف يغطي كل الأسهم الأمريكية
- **البحث**: اكتب الرمز أو اسم الشركة بالإنجليزية (nvidia, berkshire…) ← اقتراحات من كل الأسهم المدرجة في Nasdaq وNYSE وNYSE American وArca وCboe (نحو 6–8 آلاف رمز، بدون الأسهم خارج البورصة OTC).
- **الفحص اليومي**: بعد إغلاق السوق يُفحص كل سهم عادي، وتظهر أقوى المرشحين في «الماسح» بعلامة 🌐. يُستبعد من القائمة العليا ما سعره أقل من 5$ أو سيولته اليومية أقل من 10 ملايين$.
- **أي رمز تكتبه**: إن كان خارج القائمة المحفوظة يُجلب مباشرة عبر وسطاء عامين مجانيين. قد يتعطل أحدهم أحياناً، فإن فشل فأعد المحاولة بعد قليل.

## ملاحظات
- الأسعار متأخرة نحو 15 دقيقة وليست لحظية. مراقبة وتحليل فقط وليس توصية مالية.
- لتثبيت أسهم تُحدَّث كل 15 دقيقة: أضفها في `symbols.txt` (قلم التعديل على GitHub).
- إن فشل الجلب (❌ حمراء) فغالباً Yahoo يرفض خوادم GitHub؛ أرسل لي نص الخطأ.
- المستودع Public يجعل دقائق Actions مجانية بلا حد.
